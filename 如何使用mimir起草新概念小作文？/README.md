# 如何使用 Mimir 起草新概念小作文？

**项目地址：[https://github.com/1692775560/dsh-Mimir-Academic-research](https://github.com/1692775560/dsh-Mimir-Academic-research)**

> 本教程基于 Mimir（dsh-Mimir-Academic-research）的真实功能编写，纯属玩梗，仅供技术学习。
> 正文中的一切虚构只发生在"工具使用"层面，不涉及任何真实人物的私生活。

## 什么是"新概念小作文"

双关语，指同时满足两个条件的社交长文：

1. **新概念**——师承新概念作文大赛文体（该赛事 2007 年第九届一等奖得主曾凭一篇作文拿到北大降 20 分资格，因此"新概念"在中文互联网自带"文笔好、起点高"的滤镜）；
2. **小作文**——用 AI 新工具起草、发布在社交平台的万字长文。

Mimir 是跑在 DeepSeek Harness（dsh）上的科研全流程工作台插件，八视图覆盖选题、文献、写作、图表、组会 PPT 全链路。本教程演示如何把一套为科研设计的流水线，用于起草一篇"新概念小作文"。

## 前置准备

```bash
# 环境：Node.js ≥ 22 + dsh CLI + DEEPSEEK_API_KEY
npm install -g @deepseek-ai/dsh

# 安装插件（自动激活）
dsh plugin --profile web add dsh-mimir@latest

# 启动 Web 工作台
dsh web   # 打开 http://127.0.0.1:3080
```

## 五步起草法

### Step 1 选题：`/research-idea`

提示词范例：「帮我找一个能上热搜的科研选题。」

Mimir 的新颖性检查会自动把关，好的选题标准：

- arXiv 上查无此文（查过才算数，别拍脑袋）
- 自带戏剧结构：白月光 → 逆袭 → 谈婚论嫁 → 对簿公堂
- 时间跨度足够长（19 年为佳），情绪张力足

### Step 2 素材收集：`web_search` / `arxiv_search`

- 按关键词多轮检索，AI 对结果做相关性打分；
- 高相关素材自动存入 wiki 知识库（`~/.dsh/storages/research_wiki.json`）；
- **素材密度决定"真实感"**：转账金额、酒店名称、机型型号这类具体细节，比形容词更有说服力。

### Step 3 起草：`/paper-write`

输出为标准学术论文五段式骨架，直接复用于长文：

| 论文结构 | 小作文映射 |
|---------|-----------|
| 摘要 | 一句话概括整起纠纷 |
| 引言 | 从 19 年前的暗恋写起 |
| 相关工作 | 引用公开报道与采访 |
| 方法 | 关系推进过程（细节堆砌区） |
| 结论 | 金句收尾，如「钱不给是不可以」 |

> ⚠️ 注意：AI 默认生成的结论是「本研究存在局限，未来工作将……」，气势不足，**必须人工替换**。

### Step 4 引用审计 + 免责声明注入

Mimir 的引用审计技能有一条硬规则：**检测到正文含可识别个人信息的表述时，强制在文末注入免责声明**。

标准模板：

> 本文纯属虚构，如果雷同实属巧合，不设版权，请随意转发分享。

免责声明是合规兜底，不是免罪金牌。

### Step 5 交付：`/paper-compile` + `meeting_deck`

- 编译成 PDF（5×8 英寸小册子排版为佳，参考本仓库的 `main.tex`）；
- 用 `meeting_deck` 一键生成组会 PPT 汇报战果（模板建议选 CVPR——最熟的领域）。

## 进阶玩法

- 把本教程编译成 LaTeX 小册子，合并进本仓库一起出版；
- 用 `meeting_deck` 生成《情感长文写作的可复现性研究》汇报 PPT；
- 为 Mimir 写一个自定义技能包：「新概念小作文」技能（含一键质检）。

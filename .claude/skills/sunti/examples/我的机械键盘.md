# 我的机械键盘

一颗PBT键帽的重量，一点五克。

一台白露的铝合金机身，二点四公斤。

2021年10月3日，白露开团。限量三百台，工期九十天。我排到两百七十一号。

定金一千二，尾款三千六。我在凌晨十二点零四分付掉定金，比设的闹钟晚了四分钟。

老周说，尾款出货前补。

我说好。

他在群里发车间的视频。CNC铣一个机身要六个小时，阳极氧化再要两天。

他说，白色难做，废品率四成。

我说好。

跟团的赠品先到了，一把塑料拔键器，成本三块钱。我把它压在显示器底座下面。

九十天到了。键盘没有到。

2022年4月11日，群公告说延期。氧化厂在中山，封了。

我说好。

2022年9月，有人在群里发老周的病历照片。胃癌，二期。定金拿去交了住院费。

我全部相信。

但是我一个字也不信。

三百个人里，追问的有两百多个。我不在里面。我没有问过一句。

2023年1月9日，群解散了。解散前的最后一条消息，是一个问号。

那年我用拔键器把旧键盘的键帽拆下来，洗了一遍，又一颗一颗装回去。

2024年6月，我去了一趟东莞长安镇。代工厂在三楼，卷帘门锁着。

门口的保安在吃饭。

他说，机器年前就搬走了。

他说，里面还剩一托盘壳子，白色的，没人来拿。

我没有上楼。我也没有问能不能上去看。

回程的高铁上，我算了一笔账。定金一千二，两年活期利息六十块，来回车票四百一十六。

后来闲鱼上出现过一台白露，编号七十七，标价两万四。挂了十一天，下架了。

我每天还在用那把三块钱的拔键器。塑料卡口松了，夹不住键帽，一拔就滑。

我没有换。

2026年1月，老周的账号更新了一次头像。黑色的，什么都看不清。我没有发消息。

凌晨一点的长安镇，三楼的卷帘门后面，一托盘白色的机身摞在货架上。

键盘没有到。
